DAMINI INGALE PORTFOLIO — HTML + CSS ONLY

Files included:
- index.html: page content
- style.css: design, layout, animations, and responsive styling

No JavaScript file is used. The mobile navigation menu is controlled with a CSS checkbox.

Run locally:
1. Extract the ZIP file.
2. Open the damini-portfolio-no-js folder.
3. Double-click index.html to open it in your browser.
4. Or open the folder in VS Code and use Live Server.

Before publishing, replace the sample email, GitHub and LinkedIn URLs, college and education placeholders, certificate details, project repository links, and resume link with your real details.

The email button opens the visitor’s email application. There is no backend or contact form. Dashboard artwork is illustrative mockup content, not live project data.
